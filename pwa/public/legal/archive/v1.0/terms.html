Версия 1.0. Действует с момента акцепта в приложении Mood.

1. О сервисе

Mood — неофициальное приложение для студентов НИУ МЭИ, доступное как PWA и APK/TWA. Приложение не является официальным сервисом НИУ МЭИ, не одобрено и не согласовано с вузом. Приложение предназначено для лиц 18+.

2. Учётная запись

Пользователь подтверждает, что является владельцем учётной записи БАРС, которую указывает при входе, и вправе использовать её в приложении. Передача чужих учётных данных запрещена.

3. Что делает приложение

Приложение выполняет вход в БАРС от имени пользователя, получает данные личного кабинета (расписание, оценки, рейтинг, пропуски, приказы, стипендия, книги НТБ), отображает их, показывает количество непрочитанных писем и формирует уведомления о событиях.

Содержание писем не читается: обрабатываются только факт наличия новых писем, количество непрочитанных, время проверки и UID последнего известного письма.

4. Уведомления

Внутри приложения доступны уведомления с деталями (дисциплина и балл, номер/дата/заголовок приказа, статус стипендии, факт нового письма). Web Push при отдельном согласии передаёт только тип события; значения баллов, темы писем и тексты приказов в push не уходят.

Telegram используется только как внешняя ссылка на приложение и не получает данные пользователей.

5. Гостевой режим

Гость указывает имя/псевдоним и группу и получает только расписание. БАРС, оценки, почта, домашние задания, объявления и push гостю недоступны. Гость подтверждает возраст 18+ и принимает отдельное согласие.
