# Политика motion

**Motion собирается только по отдельному ТЗ. Без ТЗ — не трогать.**

Это касается:

- `promo/src/` (Remotion-сцены);
- `promo/media/video/` (готовые ролики);
- `promo/media/audio/` (звук);
- любых «улучшений», «а давай попробуем» и «я быстро поменяю».

## Правила

1. Если пользователь не попросил новый ролик и не дал бриф — **не менять
   ничего** в motion.
2. Текущий релизный ролик `media/video/mood-20s-9x16.mp4` считается
   замороженным. Он используется в публикациях как есть.
3. Идеи и предложения можно описывать текстом, но не реализовывать.
4. Новый ролик начинается с брифа в `motion/briefs/YYYY-MM-DD-slug.md`.
5. Рендер запускается только после утверждения брифа.
6. Если в брифе нет длительности, формата, сцен или звука — бриф не готов.

## Что должно быть в брифе

- цель ролика (релиз, фича, имидж);
- формат: 9:16 / 1:1 / 16:9;
- длительность;
- 3–6 сцен с текстом;
- какие экраны/кадры использовать;
- музыка/звук: свой трек или сгенерированный;
- дедлайн и кто утверждает.

## Команды

```bash
npm run audio     # пересобрать звук
npm run prepare   # скопировать медиа в public
npm run render    # отрендерить 20s 9:16
```
