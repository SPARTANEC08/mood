# Медиа

## Что здесь

```
media/
├── video/    # готовые ролики (MP4)
├── stock/    # скриншоты интерфейса
└── audio/    # сгенерированный звук
```

## Видео

- `video/mood-20s-9x16.mp4` — текущий релизный ролик: 20 секунд, 1080×1920,
  H.264 + AAC, свой саунд-дизайн.
- Видео используется **только в постах Telegram** и **только когда есть
  отдельное ТЗ на motion**.
- В Telegraph видео не встраиваем: там скриншоты и ссылка на пост/ролик.
- Не пересобирать без `motion/briefs/`.

## Скриншоты

- 22 полных экрана из мокового стенда: расписание, календарь, предмет,
  успеваемость, КМ, долги, рейтинг, пропуски, калькулятор, задания, «Важное»,
  кабинет, стипендия, приказы, НТБ, уведомления, добавление записи.
- Для статьи берём **только те экраны, которые относятся к сценарию**.
  Не надо пихать все 22.
- Для поста в Telegram скриншоты не используем: только текст и ссылка.
- Скрины сжимаются и загружаются на `https://mood-app.ru/media/` через
  `scripts/upload-media.mjs`. Telegraph upload закрыт в 2026 году.

## Аудио

- `audio/audio.wav` генерируется `scripts/make-audio.mjs` (120 BPM, 20 секунд).
- В git не коммитим; при необходимости пересобираем.

## Именование

- Видео: `YYYY-MM-DD-slug.mp4`, например `2026-11-03-mood-20s.mp4`.
- Скрин: `feature-name.png`, например `calculator-plan.png`.
- Загрузка: `npm run upload -- media/stock/10-calculator-plan.png`.
