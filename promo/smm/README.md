# SMM-процесс Mood

Один вечерний заход: изменения → сценарий → черновики → утверждение → публикация.
**Публикует только человек.** Агент не отправляет посты сам.

## Пять шагов

### 1. Собрать изменения

```bash
cd promo
npm run collect -- --date 2026-11-03
```

Скрипт смотрит `smm/last-published.json`:

- если есть `commit` — берёт `git log <commit>..HEAD`;
- если нет — `git log --since=<publishedAt>`.

Результат: `drafts/<дата>/changes.md`. Только пользовательские изменения:
`feat` / `fix` / `perf` в `pwa/`, `ios/`, `backend/server`, `backend/services`,
`backend/parser`, `backend/scheduleCache.ts`.

### 2. Написать сценарий

Агент читает `changes.md` и пишет `drafts/<дата>/scenario.md` по шаблону
`templates/scenario.md`:

- 3–6 пунктов;
- каждый пункт — факт + польза для студента;
- без внутренних деталей и выдуманных фич;
- отдельно — что показать на скринах;
- отдельно — нужен ли ролик (по умолчанию нет).

Если сценарий даёт человек — шаг 2 пропускается, агент сразу оформляет.

### 3. Собрать черновики

```bash
npm run drafts -- --date 2026-11-03
```

На выходе:

- `telegram.md` — пост по формату канала;
- `telegraph.md` — статья с разделами и `{{img:...}}`;
- если есть `assets.json` — подставляет URL уже загруженных скринов.

### 4. Проверить и утвердить

Чек-лист: `smm/approval.md`.

- факты совпадают с коммитами;
- нет внутренних терминов;
- ссылки с UTM;
- скрины соответствуют тексту;
- видео только если был бриф;
- заголовок и футер на месте.

### 5. Опубликовать и закрыть день

Публикует человек. После публикации:

```json
// smm/last-published.json
{
  "publishedAt": "2026-11-03T22:00:00+03:00",
  "commit": "<HEAD на момент публикации>",
  "telegram": "<ссылка на пост>",
  "telegraph": "<ссылка на статью>"
}
```

И строка в `smm/calendar.md`.

## Что агенту запрещено

- публиковать в Telegram и Telegraph;
- менять `promo/src/`, `media/video/`, `media/audio/` (motion только по ТЗ);
- выдумывать фичи, которых нет в коммитах;
- писать «уже работает», если это только план;
- использовать реальные ФИО и данные студентов.

## Медиа

- Telegram-пост: только текст и ссылка. Видео — редко и только по брифу.
- Telegraph: скрины фич. Загрузка:

```bash
npm run upload -- media/stock/*.png --out drafts/<дата>/assets.json
```

Скрипт сжимает до 1600 px / JPEG и заливает на `mood-app.ru/media/`.
Официальный `telegra.ph/upload` закрыт в 2026 году, поэтому используем VPS.
