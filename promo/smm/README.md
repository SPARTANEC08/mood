# SMM-процесс Mood

Один вечерний заход: изменения → сценарий → тексты → статья → пост в бота.
**Пост публикует человек.** Статью публикует скрипт.

## Четыре шага

### 1. Собрать изменения

```bash
cd promo
npm run collect -- --date 2026-11-03
```

Период по умолчанию — календарный день по Москве. Только пользовательские
коммиты: `feat` / `fix` / `perf` в `pwa/`, `ios/`, `backend/server`,
`backend/services`, `backend/parser`, `backend/scheduleCache.ts`.

Результат: `drafts/<дата>/changes.md`.

### 2. Написать сценарий

Агент пишет `drafts/<дата>/scenario.md` по шаблону `templates/scenario.md`:

- `## Пост` — 3–6 пунктов: факт + польза;
- `## Статья` — разделы `### 🎯 Название`, внутри текст и `{{img:...}}`;
- без выдуманных фич, внутренних деталей и видео.

Если сценарий дал человек — агент сразу переходит к шагу 3.

### 3. Собрать всё одной командой

```bash
npm run finish -- --date 2026-11-03
```

Команда собирает пост и статью, заливает новые скрины в GitHub Release,
публикует или обновляет Telegraph и присылает в чат бота:

- суммари дня;
- готовый пост с кликабельными ссылками.

Первый раз: `/start` у `@mood_mpei_bot`, затем `npm run tg:init`.

### 4. Проверить и опубликовать

Чек-лист: `smm/approval.md`.

- факты совпадают с коммитами;
- нет внутренних терминов и «ИИ-речи»;
- ссылки кликабельные, UTM только на сайте;
- разделы статьи с эмодзи и фото внутри;
- видео нет;
- заголовок и футер на месте.

Пост человек копирует из сообщения бота, правит и отправляет в канал.

После публикации:

```json
// smm/last-published.json
{
  "publishedAt": "2026-11-03T22:00:00+03:00",
  "commit": "<HEAD на момент публикации>",
  "telegram": "<ссылка на пост>",
  "telegraph": "<ссылка на статью>"
}
```

И строка в `smm/calendar.md`.

## Что агенту запрещено

- публиковать пост в Telegram;
- выдумывать фичи, которых нет в коммитах;
- писать «уже работает», если это только план;
- трогать `promo/src/`, `media/video/`, `media/audio/` без брифа;
- заливать медиа на прод-сервер;
- использовать реальные ФИО и данные студентов.

## Медиа

- Telegram-пост: только текст и ссылки. Скрины и видео не вкладываем.
- Telegraph: скрины внутри разделов, без подписей.
- Загрузка автоматическая в `finish`, вручную:

```bash
npm run upload -- --date 2026-11-03
```

Скрипт сжимает до 1600 px / JPEG и заливает в GitHub Release. На прод ничего
не попадает: `media/stock` и `drafts/` в `.gitignore`.
