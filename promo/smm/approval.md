# Утверждение и публикация

## Статусы

| Статус | Что значит |
|---|---|
| `draft` | черновик, можно править |
| `approved` | человек проверил, можно публиковать |
| `published` | опубликовано, ссылки записаны |

## Чек-лист перед публикацией

- [ ] Заголовок и 3–6 пунктов, без воды.
- [ ] Каждый пункт — пользовательский эффект, а не реализация.
- [ ] Нет выдуманных фич и обещаний.
- [ ] Один эмодзи, без CAPS и восклицательных знаков.
- [ ] Ссылка «Подробнее тут (тык)» ведёт на статью.
- [ ] Футер: web // tg_bot // support // GitHub.
- [ ] UTM в ссылках на сайт.
- [ ] Скрины в статье соответствуют тексту, без лишних.
- [ ] Видео только если был бриф на motion.
- [ ] Нет реальных ФИО и персональных данных.
- [ ] Статья в Telegraph открывается, картинки на месте.

## Публикация

1. Опубликовать статью в Telegraph.
2. Опубликовать пост в Telegram со ссылкой на статью.
3. Обновить `smm/last-published.json`:
   - `publishedAt`;
   - `commit` — текущий HEAD;
   - `telegram` — ссылка на пост;
   - `telegraph` — ссылка на статью.
4. Добавить строку в `smm/calendar.md`.

## Откат

Если пост опубликован с ошибкой:

- исправить пост в Telegram (редактирование);
- исправить статью в Telegraph;
- если ошибка смысловая — удалить пост и опубликовать исправленный;
- записать инцидент в `smm/calendar.md`.
