# Mood — SMM-база

Здесь живёт редакционный конвейер: изменения → сценарий → черновики поста
и статьи → утверждение → публикация. Публикует **только человек**.

## Структура

```
promo/
├── config/       ссылки, бренд, ритм
├── brand/        тон, визуал, лого и QR
├── media/        видео, скрины, звук
├── motion/       политика, шаблон брифа, брифы
├── smm/          процесс, промт агенту, правила, календарь
├── templates/    шаблоны поста, статьи, сценария
├── drafts/       черновики по датам
└── scripts/      сбор изменений, черновики, загрузка скринов
```

## Быстрый старт вечером

```bash
cd promo

# 1. Изменения с прошлой публикации
npm run collect -- --date 2026-11-03

# 2. Сценарий: drafts/2026-11-03/scenario.md
#    (пишет агент по changes.md или человек вручную)

# 3. Черновики
npm run drafts -- --date 2026-11-03

# 4. Скрины в Telegraph (по одному или списком)
npm run upload -- media/stock/*.png --out drafts/2026-11-03/assets.json

# 5. Пересобрать статью с URL картинок
npm run drafts -- --date 2026-11-03
```

На выходе:

- `drafts/<дата>/changes.md` — сырые пользовательские коммиты;
- `drafts/<дата>/scenario.md` — сценарий;
- `drafts/<дата>/telegram.md` — пост;
- `drafts/<дата>/telegram.txt` — пост для ручной вставки;
- `drafts/<дата>/telegraph.md` — статья;
- `drafts/<дата>/telegraph.html` — статья для копирования в Telegraph;
- `drafts/<дата>/assets.json` — локальный файл → URL в Telegraph.

## Правила

1. **Публикует человек.** Агент не отправляет посты в Telegram и Telegraph.
2. **Motion только по ТЗ.** Без брифа в `motion/briefs/` не трогаем
   `src/`, `media/video/`, `media/audio/`.
3. **Только пользовательские изменения.** В дайджест не идут рефакторинг,
   тесты, docs, миграции и зависимости.
4. **Скрины — в Telegraph, видео — в пост.** По умолчанию пост текстовый.
5. **Ссылки и UTM** — из `config/links.json`; пустые ссылки не выводим.

## Что заполнить сразу

В `config/links.json` пустые `bot` и `channel` — вписать реальные ссылки.
Если их нет, футер просто не покажет эти пункты.

## Что не коммитим

`public/`, `media/video/*.mp4`, `media/audio/*.wav`, `media/stock/*.png`,
`drafts/` — генерируемое и приватное. В git — только тексты, шаблоны,
скрипты и конфиги.

## Полезные файлы

- `smm/nightly-agent.md` — промт вечернему агенту;
- `smm/changelog-rules.md` — что считать новостью;
- `smm/approval.md` — чек-лист перед публикацией;
- `motion/POLICY.md` — почему motion не трогаем без ТЗ;
- `brand/tone-of-voice.md` — как писать;
- `brand/visual.md` — как выглядят скрины и видео.
