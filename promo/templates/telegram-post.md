# Шаблон поста в Telegram

> Формат с канала: заголовок, 3–6 пунктов, ссылка «тык», футер.
> Публикует человек. Агент только собирает черновик.

## Шаблон

```
🎓 {{title}}

- {{bullet1}}
- {{bullet2}}
- {{bullet3}}
- {{bullet4}}

[Подробнее об обновлении тут (тык)]({{telegraph}})

web // tg_bot // support // GitHub
```

## Правила

- Заголовок: «Обновление Mood» или «Что нового в Mood».
- 3–6 пунктов, каждый до двух строк.
- Один эмодзи на пост, обычно 🎓.
- Ссылки в футере — гиперссылки, а не голые URL:
  - `web` → сайт;
  - `tg_bot` → бот;
  - `support` → поддержка;
  - `GitHub` → репозиторий.
- Если ссылки нет в `config/links.json` — пункт не выводим.
- Ссылка «тык» ведёт на статью Telegraph и оформляется гиперссылкой:
  `[Подробнее об обновлении тут (тык)](url)`.
- UTM добавляем только к ссылке на сайт.

## Пример

```
🎓 Обновление Mood

- Калькулятор оценок стал проще: ползунок порога и план по оставшимся КМ
- Уведомление об оценке читается за секунду: предмет, КМ и балл
- «Успеваемость» и «Кабинет» больше не ждут зависший БАРС
- Готовим сайт со всей информацией о Mood

Подробнее об обновлении тут (тык) — https://telegra.ph/...

web // tg_bot // support // GitHub
```

## HTML для Telegram (если вставлять вручную)

```html
🎓 <b>Обновление Mood</b>

- Калькулятор оценок стал проще: ползунок порога и план по оставшимся КМ
- ...

<a href="https://telegra.ph/...">Подробнее об обновлении тут (тык)</a>

<a href="https://mood-app.ru">web</a> // <a href="https://t.me/...">tg_bot</a> // <a href="https://t.me/mood_mpei_sup">support</a> // <a href="https://github.com/SPARTANEC08/mood">GitHub</a>
```
