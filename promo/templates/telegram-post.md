# Шаблон поста в Telegram

> Публикует человек. Агент собирает черновик и присылает его ботом —
> так ссылки остаются кликабельными.

## Шаблон

```
🎓 Mood: обновление

- Пункт: что изменилось и чем полезно
- Пункт
- Пункт
- Пункт

[Подробнее об обновлении тут (тык)]({{telegraph}})

[web]({{web}}) // [tg_bot]({{bot}}) // [support]({{support}}) // [GitHub]({{github}})
```

## Правила

- Заголовок: `Mood: обновление` или `Mood: <тема>`.
- 3–6 пунктов, каждый до двух строк.
- Один эмодзи на пост — 🎓 в заголовке.
- Ссылка «тык» ведёт на статью Telegraph.
- Футер — гиперссылки, пустые не выводим.
- UTM только у ссылки на сайт.
- Скрины и видео в пост не вкладываем: только текст и ссылки.
- Если бот недоступен, `telegram.html` можно открыть и скопировать оттуда.
