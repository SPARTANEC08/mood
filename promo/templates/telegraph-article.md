# Шаблон статьи в Telegraph

> Собирается из `scenario.md`. Публикует человек.
> Скрины — только по теме, загружаются на `mood-app.ru/media/` через `npm run upload`.
> Публикация: `npm run publish -- --date YYYY-MM-DD`, обновление — с `--update`.
> `telegraph.html` — для быстрой проверки, `telegraph.md` — для правок.

## Структура

```
# {{title}}

{{lead: 1–2 предложения, что изменилось и почему это полезно}}

## Что нового

### {{feature1}}
{{1–2 абзаца: что было, что стало, чем пользуется студент}}

{{img:media/stock/...|Подпись}}

### {{feature2}}
...

## Скриншоты

{{img:...|Подпись}}
{{img:...|Подпись}}

## Видео

{{video:media/video/mood-20s-9x16.mp4|20-секундный обзор}}
> Видео встраивается ссылкой на пост или страницу с плеером.

## Как установить

1. Открыть `{{web}}` в Safari/Chrome.
2. «Поделиться» → «На экран Домой» (iOS) или «Установить» (Android).
3. Войти логином БАРС.

## Ссылки

- Сайт: {{web}}
- Поддержка: {{support}}
- GitHub: {{github}}
```

## Правила

- Заголовок без CAPS и восклицательных.
- Лид — 1–2 предложения, без «революции».
- Каждая фича — отдельный раздел, не сваливать всё в один список.
- Скрины подписывать: что именно видно.
- Не вставлять видеофайл в статью: только ссылку/постер.
- Не использовать реальные ФИО и персональные данные.
- UTM — только в ссылке на сайт.
- В конце — установка и ссылки.
- Если фичи ещё нет — писать «готовим», а не «уже работает».
