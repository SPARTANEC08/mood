# Шаблон статьи в Telegraph

> Эталон: https://telegra.ph/Mood-obnovlenie-11-01
> Собирается из `scenario.md` командой `npm run drafts`.
> Публикует агент скриптом, пост отправляет человек.

## Структура

```
[web](...) // [tg_bot](...) // [support](...) // [GitHub](...)

03.11.2026

Вот что нового.

#### 🎯 **Успеваемость**

Один-два абзаца. Что было, что стало, чем пользуется студент.

![](...скрин...)

![](...скрин...)

#### 🧮 **Калькулятор оценок**

Текст.

1. Шаг.
2. Шаг.
3. Шаг.

![](...скрин...)

#### [web](...) // [tg_bot](...) // [support](...) // [GitHub](...)
```

## Правила

- Заголовок страницы: `Mood: обновление` (без CAPS и восклицательных).
- Ссылки — сверху и снизу.
- Дата — `ДД.ММ.ГГГГ`.
- После даты — ровно «Вот что нового.».
- Каждый раздел — `####` + эмодзи + жирное название.
- В разделе: 1–2 абзаца и 1–3 скрина **внутри** раздела.
- Подписей под скринами нет.
- Видео в статью не вставляем и не упоминаем.
- Блоков «Как установить» и «Ссылки» нет: всё в футере.
- В статье нет дельт, средних и баллов из 100.
- Реальные ФИО и данные студентов не используем.
