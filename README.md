# Telegram-бот расписания НИУ МЭИ (Zbot)

Telegram-бот для студентов НИУ МЭИ (ts.mpei.ru) с расписанием, домашними заданиями и важными объявлениями.

## Возможности
- 📅 **Расписание**: актуальные пары напрямую с официального портала НИУ МЭИ.
- 🕒 **Точная привязка ДЗ**:
  - Если пара уже началась или идёт сейчас — ДЗ автоматически привязывается к **следующей** такой паре.
  - Учитывается московское время вне зависимости от часового пояса сервера.
  - Поддержка студенческих сокращений («матан», «инфа», «орг», «опд», «физра» и т.д.).
- 📎 **Работа с файлами**:
  - Поддержка фото, документов, видео, аудио и голосовых.
  - Временные файлы удаляются из чата при навигации, не засоряя диалог.
- 📢 **Канал-хранилище**:
  - Все ДЗ и важные сообщения публикуются в канал с тегами группы (`#ДЗ`, `#Важное`, `#ИЭ_11_26`), датой, парой и автором.
  - Прикрепленные файлы привязываются ответом к сообщению.
- 🗑 **Удаление**:
  - Возможность удалить любое ДЗ или важное сообщение с подтверждением.
  - При удалении сообщение также стирается из канала-хранилища.
- 📌 **Раздел «Важное»**:
  - Хранение объявлений группы с файлами и просмотром.

## Настройка окружения (.env)

Создайте файл `.env` в корне проекта:

```env
# Токен бота от @BotFather
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ

# ID закрытого канала-хранилища (где бот является админом)
TELEGRAM_STORAGE_CHANNEL_ID=-1001234567890
```

## Запуск

```bash
# Установка зависимостей
npm install

# Запуск бота
npm run bot

# Проверка типов TypeScript
npm run lint
```
